## Nội dung nội bộ

| Trang | Mô tả |
|---|---|
| **Kiến trúc Kỹ thuật** | Stack, infra, data flow, bảo mật hệ thống |
| **Mô hình Kinh doanh** | Gói B2B2C, bảng giá, chiến lược doanh thu |
| **Lộ trình Sản phẩm** | Roadmap theo quý, milestone, dependencies |
| **Hướng dẫn Dev** | Setup môi trường, quy trình deploy, coding conventions |
| **Admin Nhà trường** | Hướng dẫn onboarding trường, quyền quản trị |

## Nguyên tắc bảo mật
